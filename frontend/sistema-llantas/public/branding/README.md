# Branding

Guarda aquí los recursos gráficos de la aplicación.

Para el logo principal de la empresa usa preferiblemente:

- `logo-edinsa.png` si el archivo tiene fondo transparente.
- `logo-edinsa.svg` si cuentas con el logo vectorial oficial.

Angular publica automáticamente todo el contenido de `public`, por lo que luego se puede usar en la aplicación como:

```html
<img src="/branding/logo-edinsa.png" alt="EDINSA">
```

Recomendación: usa una versión horizontal o compacta, con fondo transparente y buena legibilidad sobre fondo oscuro.
